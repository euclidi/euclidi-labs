# Remaining approved scope — 0.2.0-dev

Current release is a tested development build, not a completed scientific instrument. The approved Revision 2.1 specification remains authoritative.

1. Complete approved dependency stack: Emscripten, double-precision KissFFT, Eigen, TypeScript/Vite and build reproducibility. Current compiled core uses Clang and custom FFT; Three.js r170 is locally vendored. WebGL2 data traces are present, Canvas fallback remains. Implement optional WebGPU numerical acceleration and CPU/GPU comparison.
2. Finish measurement quality: independent synthetic vowel/Praat Burg formant and McLeod tests; wider weighting, filter and resampler reference fixtures; frequency-response calibration and valid persisted profiles; HNR, calibrated uncertainty, precise percentile/time-weighted reference comparison; broad-band transfer and phase validation. Expand generator noise, sweeps and modulation, user-defined arbitrary graphs with explicit safe delayed feedback, multiple independent acquisition streams. Stereo recording is bounded to 10 minutes; complete 30-minute memory-safe capture.
3. Finish physics: adaptive spatial grids and geometry editor, arbitrary material placement and full receiver capture, calibrated coupling, absorbers/reflection/interference/convergence tests, FEM or validated complex structural shapes and discrete grain contacts, further vocal/waveguide/ripple validation and true high-fidelity offline modes. Current spatial grid is fixed at 160×100, reduced-order structures/particles and limited offline files (60 s). No 3D propagation is claimed.
4. Test real PC system audio on Windows/Chrome/Edge and physical microphones/phone pairing, permission and interruption recovery across desktop/mobile browsers, performance and latency on identified hardware, 30-minute capture, privacy/network inspection, calibrated SPL against reference equipment, accessibility and visual geometry review. Chromium CI tests use synthetic hardware and cannot establish actual device behavior.
5. Maintain existing Euclidi Labs catalog, source documentation, version labels and reproducible acceptance evidence. Verify public Pages URL and version independently after merge; never claim full scientific validation or certification from a passing smoke test.
