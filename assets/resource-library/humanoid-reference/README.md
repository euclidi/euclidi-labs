# Humanoid motion reference

`animated-mannequin/mannequin.glb` is a skinned humanoid with 46 embedded clips; `CLIPS.txt` lists them. It can support future motion visualization experiments. It is presentation data, not an anatomical, biomechanical or dynamics model. The CC0 file was retrieved from the demo in the local [Foot IK Grounder Lite](https://dangalg.itch.io/foot-ik-grounder-godot) archive; its license is included. Not integrated into Labs.
