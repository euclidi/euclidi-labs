# Audio test signals

Twenty-three deterministic one-second PCM fixtures for digital audio pipeline development. The suite covers silence, DC offset, impulses, 440 Hz and 1 kHz tones, summed tones, square/triangle/sawtooth waves, linear and logarithmic 20 Hz–20 kHz sweeps, seeded white noise, fades, clipped and quiet signals, mono/stereo routing, in/anti-phase stereo, and 22.05/48/96 kHz with 16- or 24-bit PCM.

All samples are generated by `tools/generate_audio_fixtures.py`. The manifest records signal parameters, frame counts, file sizes, and SHA-256 checksums. Rebuild and validate from the `euclidi-labs` repo root:

```powershell
python tools\generate_audio_fixtures.py
python tools\validate_audio_fixtures.py
```

Validation checks the exact manifest file set, hashes, PCM headers, and byte-for-byte deterministic regeneration. These are CC0 synthetic digital fixtures, not recorded acoustic references or loudspeaker/microphone calibration signals.
