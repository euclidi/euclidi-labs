# Mechanical library

Port of Euclidi Games' mechanical library v1.4.1, adapted for Labs. It reads the Classic catalog HTML rather than maintaining an independent inventory. The rotary storage, inspection, transfer, lift, sound, search, category filters and launch controls remain available as experiments are registered. With no inventory it intentionally displays an empty machine. Requires a WebGL-capable browser; Classic is the fallback. Three.js is bundled under MIT. See [spec](SPEC.md), [roadmap](ROADMAP.md), [status](STATUS.md).
